## Performance and capacity protocol

No load generator or instrumentation is newly installed. Choose a tool/operator and isolated approved target first; never load-test the current development project or a real cohort without separate coordination. Seed **synthetic** 50 profiles, 100 opportunities, 500 applications, 50 collaborations, 2,000 messages with valid relationships/lifecycles; do not bypass production authorization to simulate success. Record the fixture manifest and cleanup scope. Use 10 distinct active sessions and an **aggregate 2 requests/second for 15 minutes** (about 1,800 offered requests after warm-up); record actual achieved rate/concurrency rather than multiplying 2 rps by 10. Include discovery/detail, applications, messages and status actions; exclude bulk file transfers from normal latency samples and measure them separately. Keep sessions/rate fixed, stop for suspected authorization/data loss or uncontrolled resource growth; no automatic scaling/purchases.
